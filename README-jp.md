# コンパイラコンパイラ解説

> 言語の文法を書き下すと、その言語のコンパイラができあがる ── そして仕上げに、その仕組み自身を自分の文法で記述し、その記述から自分自身を作り直す。

それが**コンパイラコンパイラ**です。実用例としては yacc や bison が有名ですが、本サイトでは**もっと小さな自己定義コンパイラコンパイラ**を題材に、**1 行ずつ** 追いかけながら、内側からその仕組みを見通します。

<!-- SEO intro added by setup-github-pages; review and adjust -->

「**自分でコンパイラを作ってみたい**」「**字句解析・構文解析・コード生成** がどう繋がっているのか知りたい」「**自己定義** や **メタコンパイラ** という発想を、小さな実例で確かめたい」 ── そんな人のための **コンパイラコンパイラ入門**です。扱うテーマは **再帰下降構文解析**、**BNF と形式文法**、**バックトラック**、**生成規則**、**出力制御**、そして処理系が自分自身を記述する **自己定義** まで。C言語の基本文法とプログラムの流れがわかれば、特別な前提知識は必要ありません。

<!-- /SEO intro -->

読み終える頃には、実在する小さな自己定義コンパイラコンパイラの全コードを通読し、それぞれの行が何をしているかを内側から理解できるようになります。最も面白いのは最後のパート ── 処理系が **自分自身の文法を、自分の文法で記述し、その記述から自分自身を再生成する** 場面です。
